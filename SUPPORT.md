# Getting help

- **Questions and ideas:** GitHub Discussions of `dyng-dev/dyng`.
- **Bugs and wrong results:** GitHub Issues (please include the commit, the backend, the
  compiler and a minimal input).
- **Security problems:** see [SECURITY.md](SECURITY.md); do not open a public issue.
- **Conduct:** see [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

There is no private e-mail support. dynG is pre-alpha; the documentation that exists is in
[README.md](README.md), [docs/](docs/) and the algorithm pages under
[docs/algorithms/](docs/algorithms/).
