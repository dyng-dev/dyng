# hyper_sssp: shortest hyperpaths

Maturity: **experimental**. Header: `<dyng/hyper_sssp.hpp>`. Container: hypergraph.
Oracle: `compute`. Determinism: `exact_value`. Backends: sequential. Generated by
`scripts/new_algorithm.py --container hypergraph`; every TODO below is for the contributor
(docs/developer/conformance.md, "Adding an algorithm").

:::{note}
The generated `update()` applies the batch and **recomputes from scratch**
(`stats.fallback_used` is true): the scaffold starts green, and the conformance kit keeps
checking the algorithm while it is made incremental.
:::
