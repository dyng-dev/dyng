# triangle_delta: the triangle count of an undirected graph (teaching material)

Maturity: **experimental**. Header: `<dyng/triangle_delta.hpp>`. Oracle: `compute`.
Determinism: `exact_value`. Backends: sequential, openmp. Generated by `scripts/new_algorithm.py`;
every TODO below is for the contributor (docs/developer/conformance.md, "Adding an algorithm").

:::{note}
The generated `update()` applies the batch and **recomputes from scratch**
(`stats.fallback_used` is true): the scaffold starts green, and the conformance kit keeps
checking the algorithm while it is made incremental.
:::
