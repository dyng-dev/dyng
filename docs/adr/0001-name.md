# ADR 0001: Name: dynG

- **Status:** Accepted
- **Date:** 2026-09-27
- **Deciders:** S M Shovan (lead maintainer)

## Context

The library unifies six research repositories (MOSP-CUDA, MOSP-OpenMP, MOSP_ESCHER,
ESCHER-GPU, LabelPropagation-CUDA, CycleEnumeration-GPU) into one project for dynamic
(batch-update) graph and hypergraph algorithms on GPUs. It needs one name for the repository,
the C++ namespace, the CMake package, the Python distribution and the documentation. A naming
study recommended *Braidrock*; *evoGraph* was dropped because of EvoGraph (ISC'17, same field).

Availability on 2026-09-27: `dyng` is free on PyPI, TestPyPI, conda-forge and Read the Docs;
the GitHub user name `dyng` is taken, the organization name `dyng-dev` is free. Similar names in
the field: DyGLib, DynGEM and the R package `dyngen` (not conflicts, but they share search
results).

## Decision

- The project is named **dynG** ("dynamic graphs"), written with a lower-case *dyn* and a
  capital *G*. It fits the family of the author's systems (DynaMOSP, DynLP, DynTruCy).
- All identifiers are lower case: C++ `namespace dyng` and `#include <dyng/...>`; CMake
  `find_package(dyng)` with targets `dyng::dyng` and `dyng::testing`; macros, options and
  environment variables `DYNG_*`; Python `import dyng`, distributions `dyng`, `dyng-cu12`,
  `dyng-cu13`; executables `dyng` and `dyng-bench`; file extensions `.dgt`, `.dgb`, `.dgc`;
  citation key `dyng2027`.
- The GitHub home is **`dyng-dev/dyng`** (decision O1′), a new organization.
- The name is always written with its tagline, "dynG: dynamic graph and hypergraph updates on
  GPUs", and the README states: "dynG = dynamic graphs; inspired by Gunrock; not affiliated".

## Consequences

- There is no rename machinery in CI; `scripts/rename_project.py` stays optional.
- The PyPI name is reserved early with a real 0.0.1 package (ADR 0014, checkpoint A3).
- conda-forge names cannot be reserved; the name is claimed with the conda-forge submission
  (planned for 0.3).
- A trademark search (USPTO classes 9 and 42) is done before 1.0.
