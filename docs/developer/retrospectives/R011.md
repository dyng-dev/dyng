## Deviations and decisions (each with the same intent)

1. **The CHANGELOG section was renamed**, not followed by a new `[0.1.0]` section: nothing in
   the library changed since 0.1.0rc1, so a separate section would only list the version and
   the documents. The renamed section keeps the record of 0.1.0rc1 and adds a "Final release
   (R011)" entry; the link reference `[0.1.0rc1]` is dropped with its heading (the tag
   `v0.1.0rc1` stays, and the summary names it).
2. **The order of the checks.** The `packaging` and `tests` checks ran at `261d03d` (the
   version and the status texts), before this retrospective and the developer plan's status
   line, which are outside their scopes; the `repo` checks (`ci/check.sh --parity`,
   `ci/gpu_local.sh`) ran after the last change outside `benchmarks/results/`, so this
   retrospective names their results by reference to the certificate. The mutation CTests ran
   in the `ci/gpu_local.sh` clone (the same `dev-cuda` build) rather than in the sanitizer
   clone.
3. **Step 8 on one machine.** The smoke test was run on the GPU machine (the CPU wheel's host
   backends); no separate CPU-only machine is available to this milestone. The wheel has no
   CUDA backend, so the two runs test the same code; the hosted CI's sdist and wheel jobs cover
   other machines.
4. **A retrospective of its own** (R011) instead of a fourth step of R010, since the final
   release is its own milestone.
