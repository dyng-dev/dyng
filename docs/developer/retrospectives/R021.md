# Retrospective: R021 (the final-release pull request for 0.2.0)

Status: **in progress** on the branch `release-0.2.0-final` (from `main` at `406c3a6`, the merge
of pull request #11 with R020; the signed tag `v0.2.0rc1` points there). Release 0.2.0 is M7 +
M6 (PLAN Appendix F); its release candidate 0.2.0rc1 is on TestPyPI since 2026-10-09 (`dyng`,
`dyng-cu12` and `dyng-cu13`, `release.yml` run 37871452302, attempt 3). R021 smoke-tests that
release candidate from TestPyPI (`docs/developer/release.md` step 8), makes the final-release
pull request (step 9: the version, the CHANGELOG, `CITATION.cff`, the status texts, the
approvals log) and carries the release candidate's certificate over to
`benchmarks/results/0.2.0/`. Nothing is published by this milestone: the orchestrator pushes the
branch; the author merges the pull request; the AI assistant pushes the signed tag `v0.2.0` and
creates the GitHub Release on the author's behalf (GOVERNANCE.md, 2026-10-06); the author
approves the PyPI deployments `pypi-cu12` and `pypi-cu13` (one dialog), then `pypi`. The planned
tag day is **2026-10-14** (UTC).

## Step 1: the smoke test of 0.2.0rc1 from TestPyPI (rc-smoke)

**Result: passed, everywhere; nothing to fix.** No defect of the code or of the documentation
was found, so the library and the release candidate's documents are unchanged by this step and
the certificate can still be carried over (step 9 of `release.md`).

### What it means for the release

- Acceptance criterion 1 is met: no blocker for the final release from the release candidate.
- No code, test or document changed in this step, so the library is still that of 0.2.0rc1's
  measured commits and the certificate can be carried over (release.md step 9).
- `release.md` step 8 names "a CPU machine and the GPU machine". As for 0.1.0 (R011), only the
  GPU machine is available to this milestone; the CPU package's host backends ran on it, and the
  plugins' behaviour on a machine without a GPU or a driver was checked with the two fallbacks
  above (`CUDA_VISIBLE_DEVICES=` and `ci/without_cuda_driver.sh`); the hosted runners of the
  release run checked the plugins' install without a GPU too (its "Plugin cuN install test, no
  GPU" jobs, green).
